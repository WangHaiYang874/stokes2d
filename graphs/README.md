# Graphs Directory

This directory contains notebooks focused on visualizing and analyzing different geometric configurations and their flow patterns.

## Files

### Visualization Notebooks
- **`caps.ipynb`** - Visualizes cap (inlet/outlet) geometries and their flow behavior
- **`cross_shaped copy.ipynb`** - Analysis and visualization of cross-shaped pipe junctions

## Purpose

These notebooks provide:
1. **Geometric visualization**: Clear visual representation of different pipe configurations
2. **Flow pattern analysis**: Understanding how geometry affects flow characteristics
3. **Design validation**: Visual verification that geometric constructions are correct
4. **Educational materials**: Illustrations for understanding pipe flow behavior

The visualizations help in:
- Debugging geometric construction algorithms
- Validating flow solver accuracy through visual inspection
- Creating figures for documentation and presentations
- Understanding the relationship between geometry and flow physics
